# Product-universe hero

Only `Casestudies.html` hero markup and its page-scoped CSS/module are changed. The existing header and everything below the hero remain intact. Home, About, and project pages are unchanged.

`portfolio-hero-scene.js` imports renderer, geology, loaders, and animation/visibility/reduced-motion lifecycle from `hero-3d-core.js`. Project routes, optimized preview assets, identities, and orbital planes are configured at the top of the module. All moon positions and line paths use the same inclined 3D transforms, with normal depth testing and mesh raycasting. Previews and labels are hidden by default. One lazy-loaded preview is expanded only on hover, keyboard focus, or touch selection. A 210ms grace period supports moving to the preview. Keyboard links expose the same seven routes. Mobile uses three moons and first-tap selection; a second tap or preview link opens the project.

Visual checks: 1920×1080, 1600×900, 1440×900, 1366×768, 834×1194, 390×844. Screenshots and motion recording are under `output/portfolio-hero-review`. Local Chromium sampling returned approximately 60 FPS; this is a local result, not a guarantee on every device. Hover/cursor selection, E-Wallet navigation, mobile selection, reduced-motion freezing, keyboard focus, and scroll transition were checked. Normal page runs reported no browser errors. Protected page checksums and the below-hero HTML comparison passed.

Landscape uses `portfolio-landscape.webp`, a landscape-only alpha derivative of the existing `portbg.webp`, retaining the original dimensions, crop, and masking. The obsolete full composition is requested only in the failure/no-JavaScript fallback.

Moon sizes, orbital durations, axial durations/tilts, terrain scale, roughness, and atmosphere strengths are deterministic per-project settings. A perspective camera supplies depth-based apparent size, and one outer moon counter-orbits. Orbital paths retain real depth occlusion. The latest art-direction pass enlarges the main planet approximately 28%, with a small right/down adjustment. IMPACT ACROSS uses the LP orange/amber gradient. Two translucent mineral-dust shells use differential rotation (1.013× and 1.022×). Perspective-aware atmospheric scattering and restrained rays keep the sun/rim coherent.

Loading fix: the head establishes a black base and hides the canvas/fallback before paint. Hero text appears immediately. The critical geology atlas is awaited before scene creation; after the first completed render, the next animation frame reveals the canvas with a 500ms opacity fade. Preview images remain interaction-loaded. Module/init failures activate the fallback.

Moon lighting pass: one finite hidden sun position is derived from the approved main-planet light vector. Preview border reflection responds to sunlight. Linear THREE.Color albedo is shaded with the existing ACES approximation and sRGB output; no shadow maps or new texture loads are introduced.

Home itself is unchanged. Two reusable meteor slots and two impact slots share the existing lifecycle; there is no second renderer or animation loop. The first deliberate impact waits until readiness plus 4–6 seconds; subsequent events use 5–10-second spacing with occasional 10–15-second quiet intervals. Flybys, atmospheric skims, main-planet impacts, use constrained trajectory bands (45% impacts, 25% skims, 30% flybys). Actual depth testing provides occlusion. Impacts illuminate only nearby terrain and expire after 6.5 seconds, following the shader's rotating geological coordinates. Reduced motion clears all effects, and visibility pauses their clock. Mobile uses six ejecta particles and longer spacing. Header/copy protection is enforced in trajectory selection and effect shaders.
