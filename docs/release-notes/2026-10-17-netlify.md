# Approved cinematic release for Netlify

The release preserves the approved cinematic pages and full-quality 24,986,424-byte spacecraft. Journey opens with a readable eight-chapter page and a light preview; the full interactive scene loads on activation. Approved Kenney CC0 engine and touchdown sounds replace the uncertain audio, and Font Awesome Free plus independent SVG primitives replace the Pro icon dependency. Attribution and licenses are in the published credits and asset license files.

Build the reviewed package with `node build-release.mjs`. The release inventory verifies 545 static files and both server sources before copying the allowlisted files to `output/stage7-release`. Keep secrets, experimental assets and local review material outside that output. The Netlify build and function directory are configured in `netlify.toml`; `api/contact.js` remains shared with the Request/Response adapter at `netlify/functions/contact.mjs`.

Set `RESEND_API_KEY`, `CONTACT_FROM` and `CONTACT_TO` in Netlify's environment controls.
