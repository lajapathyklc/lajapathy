Norton OPS: Security & Monitoring Platform

A data-heavy security platform redesigned to make system health, incidents, and response workflows easier to understand.

Real-time monitoringAnalytics workflows

The
Problem

Security and operations teams struggled to monitor and act on large volumes of system data across fragmented dashboards.

  • System health and incidents were hard to see in real time
  • Noisy datasets obscured critical signals
  • Monitoring, analysis, and response workflows were inefficient

Key
Insights

Visibility without prioritization creates noise; teams need clear signals and actionable context.

  • Real-time data needs strong hierarchy
  • Reducing noise is as important as surfacing information
  • Structured context improves decision confidence

My Role &
Ownership

Led UX strategy and product design for an enterprise security and monitoring platform.

  • Defined UX direction for monitoring and analytics
  • Synthesized research and workflow analysis
  • Built scalable patterns for data-heavy interfaces
  • Aligned product, engineering, and design decisions

Constraints &
Complexity

  • Handle large-scale, real-time data streams
  • Support expert users making time-critical decisions
  • Balance data density with clear prioritization
  • Maintain consistency across complex system interactions

Key Product &
UX Decisions

  • Structured dashboards with clearer data hierarchy
  • Emphasized critical signals through grouping and visual weight
  • Used modular layouts for flexible data visualization
  • Applied progressive disclosure to reduce overload
  • Standardized analytics interactions and monitoring navigation

Tradeoffs &
Decisions

  • Prioritized critical insights over showing every data point at once
  • Standardized dashboards while limiting deep customization
  • Focused on actionable insight over exploratory views

User Flow
Transformation

Connected monitoring, investigation, and response through a clearer signal-to-action path.

Component Thinking

  • Reusable components for charts, tables, and summaries
  • Shared patterns across monitoring modules
  • Scalable dashboard architecture
